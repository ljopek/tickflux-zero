Flowdot defines the components, memory slots, routes, travel durations, and visual reactions. JavaScript supplies the prices, exact event order, replay controls, and timestamp annotations. Implementation notes ↗


  
Teaching fixture, not live telemetry. Prices and timing are illustrative; playback stretches logical milliseconds into teaching seconds. Tier intervals are a proposed engine extension. Tick tags, versions, and replacement counts are teaching annotations. Independent tier clocks start at different phases. Teaching holds expose queued IDs and overruns; real processing is vastly faster. Later chapters compress quiet intervals and show one owning shard’s loop. Feed-status messages reach every shard in the engine; other owners’ control copies are not expanded here. Chain changes are explicit teaching checkpoints, not implemented live reconfiguration. LVC reads are idealised, ordered observations, not a claim of atomic 64-byte snapshots. Blend-age exclusion (2,000 ms) and FX quality signalling (500 ms) are separate policies.
