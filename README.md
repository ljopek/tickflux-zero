# TickFlux Zero

A high-performance market-data blending and distribution engine.

This public repository hosts the **Flowdot tick-journey diagram** — an animated
walkthrough of how a tick travels through the Zero engine, from feed ingress to
blended, derived, fanned-out delivery.

## Live demo

**[View the tick-journey diagram →](https://ljopek.github.io/tickflux-zero/tick-journey/)**

The demo source lives in [`docs/tick-journey/`](docs/tick-journey/) and is built
on [Flowdot](https://github.com/ljopek/flowdot).
